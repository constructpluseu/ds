# Tooltip <StatusBadge status="disponivel" />

Explicação curta e contextual associada a um elemento, mostrada apenas quando o utilizador
passa o cursor ou o foco de teclado sobre ele.

## Quando usar

- Para clarificar um ícone sem rótulo visível, ou dar contexto adicional a uma ação (ex.: motivo de um botão desativado).

## Quando não usar

- Para informação essencial à conclusão de uma tarefa — essa deve estar sempre visível, nunca escondida num tooltip.
- Para conteúdo interativo (links, botões) dentro do próprio tooltip — use **Toggletip** *(planeado)*.

## Anatomia

Elemento gatilho (qualquer componente focável) + balão de texto posicionado relativamente a ele,
com uma das 4 direções possíveis.

## Tamanhos

Largura máxima fixa de 16rem; o texto quebra em várias linhas quando necessário.

## Estados

| Estado | Comportamento |
|---|---|
| Oculto | `opacity: 0`, não interfere com cliques (`pointer-events: none`). |
| Visível | Aparece após hover ou foco no gatilho, com um leve deslize de entrada. |

## Comportamento

- Mostra-se tanto por `hover` como por foco de teclado — nunca é exclusivo do rato.
- Fecha-se automaticamente ao sair do hover, perder o foco, ou (dependendo da implementação) ao premir Escape.
- Nesta fase não reposiciona automaticamente para evitar sair do viewport (sem motor de colisão) — escolha a direção (`placement`) sabendo onde o gatilho normalmente aparece no layout.

## Conteúdo

- Texto curto, idealmente uma frase: **"Guarda as alterações"**, não um parágrafo.
- Nunca repita o que o rótulo visível já diz — o tooltip acrescenta informação, não duplica.

## Acessibilidade

- **Papel:** `tooltip`, associado ao gatilho via `aria-describedby`.
- **Teclado:** aparece ao focar o gatilho com `Tab`, desaparece ao sair do foco.
- **Leitor de ecrã:** o conteúdo do tooltip é lido como descrição adicional do elemento focado, sem interromper o fluxo de navegação.

Nota de implementação: no Vue, o slot expõe `describedBy` para ligação manual de
`aria-describedby` no elemento projetado; no React e Angular essa ligação é automática.

## Relacionados

- **Toggletip** *(planeado)* — para conteúdo interativo acionado por clique.
- **Popover** *(planeado)* — para conteúdo rico e mais extenso.
