# Navegação (Shell) <StatusBadge status="disponivel" />

Cabeçalho (`Header`) e menu lateral (`Side Nav`) que enquadram toda a aplicação — o esqueleto de navegação de nível superior, distinto da navegação dentro de uma página (`Tabs`, `Breadcrumb`).

## Quando usar

- Como moldura fixa de uma aplicação autenticada, com a marca, ações globais (perfil, notificações) e a navegação principal entre secções.
- `Header` e `Side Nav` são dois componentes independentes, feitos para serem usados **em conjunto** — o botão de menu do `Header` tipicamente controla a visibilidade do `Side Nav` em ecrãs estreitos.

## Quando não usar

- Para navegação dentro do conteúdo de uma página (secções de um formulário longo, por exemplo) — use `Tabs` ou `Accordion`.
- Para menus de ações pontuais — use `Dropdown Menu`.

## Anatomia

**Header**: botão de menu opcional + marca/logótipo + área de ações à direita (conteúdo livre, projetado pelo consumidor).
**Side Nav**: lista de itens de navegação; itens com sub-itens funcionam como secções expansíveis (padrão de disclosure), até um nível de profundidade.

## Estados

| Estado | Componente | Comportamento |
|---|---|---|
| Menu fechado | Header | Ícone ☰, `aria-expanded="false"` no botão de menu. |
| Menu aberto | Header | Ícone ✕, `aria-expanded="true"`. |
| Item ativo | Side Nav | `aria-current="page"`, destacado visualmente. |
| Grupo fechado/aberto | Side Nav | Seta ▸/▾, sub-itens só no DOM quando abertos. |
| Side Nav oculto | Side Nav | `open={false}` remove a navegação da vista (usado em ecrãs estreitos). |

## Comportamento

- **Componentes controlados e independentes**: nem o `Header` nem o `Side Nav` guardam estado próprio — `navOpen`/`onMenuToggle` no `Header`, e `expandedIds`/`onExpandedChange` no `Side Nav` são geridos pela aplicação. É essa mesma variável (`navOpen`) que a aplicação normalmente passa como `open` ao `Side Nav`, ligando os dois componentes.
- O `Side Nav` suporta **até dois níveis**: itens de topo e, opcionalmente, um nível de sub-itens por item. Não é uma árvore genérica — para hierarquias mais profundas, use `Tree View`.
- Clicar num item de topo sem sub-itens navega diretamente (é um `<a>` nativo); clicar num item com sub-itens expande/recolhe o grupo sem navegar.
- A área de ações do `Header` aceita qualquer conteúdo — normalmente um menu de utilizador, notificações ou uma busca (`Search`).

## Conteúdo

- A marca no `Header` é o nome do produto, não um slogan.
- Os rótulos do `Side Nav` nomeiam a secção diretamente: **&ldquo;Financeiro&rdquo;**, não **&ldquo;Área financeira da aplicação&rdquo;**.

## Acessibilidade

- O `Header` usa `<header>` nativo; o botão de menu tem `aria-label` que muda consoante o estado ("Abrir menu de navegação"/"Fechar menu de navegação") e `aria-expanded`.
- O `Side Nav` usa `<nav aria-label="…">` — dê um `label` descritivo quando houver mais do que uma região de navegação na página (ex.: para distinguir de um `Breadcrumb` também presente).
- O item ativo usa `aria-current="page"`, não apenas uma classe visual.
- Os botões de secção expansível têm `aria-expanded` a refletir o estado.

## Relacionados

- **Breadcrumb** — navegação estrutural dentro de uma secção, complementar ao `Side Nav`.
- **Dropdown Menu** — para o conteúdo típico da área de ações do `Header` (menu de utilizador).
- **Tree View** — quando a hierarquia de navegação tem mais de dois níveis.
