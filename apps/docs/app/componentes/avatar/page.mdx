# Avatar <StatusBadge status="disponivel" />

Representa uma pessoa ou equipa através de uma imagem ou, na sua ausência, das iniciais do nome.

## Quando usar

- Para identificar o responsável por uma obra, tarefa ou comentário.
- Em listas de equipa, menus de utilizador, ou históricos de atividade.

## Quando não usar

- Para representar uma entidade não-pessoal (ex.: uma empresa fornecedora) — considere um logótipo ou ícone dedicado.

## Anatomia

Círculo com imagem (`src`) ou iniciais calculadas a partir do `name` + indicador de estado opcional no canto inferior direito.

## Estados

| Estado | Comportamento |
|---|---|
| Com imagem | Mostra `src`, recortada em círculo (`object-fit: cover`). |
| Sem imagem | Mostra as iniciais (primeira + última palavra do nome) sobre fundo `bg.brand`. |
| Com indicador | Ponto colorido no canto inferior direito: `online` (verde), `busy` (vermelho), `away` (âmbar). |

## Comportamento

- As iniciais são calculadas automaticamente a partir de `name` — não é necessário fornecê-las manualmente. Um nome de uma palavra usa apenas a primeira letra.
- Se `src` falhar a carregar, esta fase não faz fallback automático para iniciais — planeie fornecer imagens fiáveis ou omitir `src`.

## Conteúdo

- `name` deve ser sempre o nome completo real da pessoa — é também o que é lido por leitores de ecrã.

## Acessibilidade

- **Papel:** `img`, com `aria-label` igual ao nome completo — funciona tanto com imagem como com iniciais.
- A imagem interna tem `alt=""` (decorativa), evitando duplicar o anúncio do nome já feito pelo `aria-label` do contentor.
