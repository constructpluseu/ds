# Text Input <StatusBadge status="disponivel" />

Campo de texto de uma linha para dados curtos e previsíveis: nome, NIF, email, número de
contrato. É o componente base de qualquer formulário na plataforma Construct+.

## Quando usar

- Para um único valor de texto, número de telefone ou email numa única linha.
- Quando o comprimento esperado da resposta é curto (até uma linha visível).

## Quando não usar

- Para texto longo ou descrições — use **Textarea**.
- Para escolha entre opções conhecidas — use **Select** ou **Radio Button**.

## Anatomia

1. **Label** — identifica o campo; obrigatório sempre que possível.
2. **Campo** — a área de introdução de texto.
3. **Texto de ajuda** — instrução opcional sob o campo.
4. **Mensagem de erro** — substitui o texto de ajuda quando a validação falha.

| Estado | Comportamento |
|---|---|
| Default | Contorno `border.default`; escurece para `border.strong` no hover. |
| Focus visible | Contorno `border.focus` + anel de destaque (`shadow.focus-ring`). |
| Disabled | Fundo `bg.disabled`, texto `text.disabled`, sem interação. |
| Invalid | Contorno e anel de foco em `border.danger`; associado à mensagem via `aria-describedby`. |

## Comportamento

- O `label` é sempre associado ao campo via `for`/`id`, gerado automaticamente quando não fornecido.
- `errorText`, quando presente, substitui visualmente `helperText` e marca `aria-invalid="true"`.
- Não aplica máscara de formato automaticamente — máscaras (NIF, telefone) são responsabilidade do formulário que o utiliza.

## Conteúdo

- O label identifica o dado, não a ação: **"Nome da obra"**, não **"Escreva o nome da obra"**.
- Mensagens de erro explicam como corrigir: **"Introduza um NIF com 9 dígitos"**, não **"Valor inválido"**.
- Use `placeholder` apenas como exemplo de formato, nunca como substituto do label.

## Acessibilidade

- **Papel:** nativo de `<input>`.
- **Teclado:** comportamento nativo de campo de texto (Tab, seleção, edição).
- **Leitor de ecrã:** o label é anunciado antes do valor; texto de ajuda/erro é anunciado via `aria-describedby`, sem interromper a leitura do valor.

## Relacionados

- **Textarea** — para texto multilinha.
- **Number Input** *(planeado)* — para valores numéricos com incremento/decremento.
- **Select** — para escolha entre opções conhecidas.
