# Pagination <StatusBadge status="disponivel" />

Navega entre páginas de um conjunto de resultados demasiado grande para mostrar de uma vez.

## Quando usar

- Para listas/tabelas com muitos resultados (ex.: histórico de obras, catálogo de materiais).

## Quando não usar

- Para listas curtas que cabem inteiramente no ecrã — paginação desnecessária adiciona fricção.
- Para carregamento contínuo (infinite scroll) — esse é um padrão diferente, não implementado por este componente.

## Anatomia

Indicador de posição (&ldquo;Página X de Y&rdquo;) + botões de navegação anterior/seguinte.

## Variantes

  <PaginationDemo />

## Tamanhos

Um único tamanho — botões de 2rem, consistentes com controlos de apoio como o fecho do Modal.

## Estados

| Estado | Comportamento |
|---|---|
| Default | Ambos os botões ativos. |
| Primeira página | Botão &ldquo;Página anterior&rdquo; desativado. |
| Última página | Botão &ldquo;Página seguinte&rdquo; desativado. |

## Comportamento

- Esta fase cobre apenas navegação anterior/seguinte — não mostra números de página individuais. Para conjuntos muito grandes, isto evita a complexidade de reticências (&ldquo;…&rdquo;) e intervalos de páginas, mantendo o componente simples e previsível.
- É responsabilidade de quem usa o componente atualizar os dados mostrados quando `onPageChange`/`update:page`/`pageChange` disparar — o componente não busca dados.

## Conteúdo

- O texto de estado usa sempre o formato &ldquo;Página X de Y&rdquo;, nunca abreviado.

## Acessibilidade

- **Papel:** `<nav aria-label="Paginação">` envolvendo os controlos.
- Os botões têm `aria-label` descritivo (&ldquo;Página anterior&rdquo;/&ldquo;Página seguinte&rdquo;), não apenas o símbolo visual `‹`/`›`.
- Botões nos limites (primeira/última página) usam o atributo `disabled` nativo, removendo-os da navegação por Tab.
