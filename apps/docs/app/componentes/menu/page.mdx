# Dropdown Menu <StatusBadge status="disponivel" />

Lista de ações contextuais acionada a partir de um botão, com navegação por teclado.

## Quando usar

- Para agrupar ações secundárias pouco frequentes que não justificam botões próprios (ex.: "Editar", "Duplicar", "Arquivar", "Eliminar" numa linha de tabela).

## Quando não usar

- Para 2-3 ações sempre visíveis e igualmente importantes — mostre-as como **Button** diretos.
- Para conteúdo que não são ações (texto, imagens) — use **Popover**.

## Anatomia

Botão gatilho + painel com uma lista vertical de itens de ação.

## Tamanhos

Largura mínima de 12rem, cresce conforme o texto dos itens.

## Estados

| Estado | Comportamento |
|---|---|
| Fechado | Painel ausente do DOM. |
| Aberto | Painel visível, primeiro item focável por teclado. |
| Item disabled | Opacidade 50%, fora da navegação por setas. |
| Item danger | Texto em `text.danger`, para ações destrutivas (ex.: "Eliminar obra"). |

## Comportamento

- **Setas ↑ ↓** navegam entre itens habilitados; **Home**/**End** saltam para o primeiro/último.
- Selecionar um item (clique ou Enter/Espaço) executa `onSelect` e fecha o menu, devolvendo o foco ao botão gatilho.
- Fecha ao clicar fora ou premir Escape, devolvendo sempre o foco ao gatilho.

## Conteúdo

- Rótulos de ação seguem a mesma regra do **Button**: verbo no infinitivo, específico ao contexto ("Eliminar obra", não apenas "Eliminar").
- Ordene os itens por frequência de uso, com ações destrutivas sempre no fim.

## Acessibilidade

- **Papéis:** `menu` no painel, `menuitem` em cada opção, `aria-haspopup="menu"` e `aria-expanded` no gatilho.
- **Teclado:** segue o padrão WAI-ARIA APG de menu button — setas para navegar, Enter/Espaço para selecionar, Escape para fechar com retorno de foco ao gatilho.

## Relacionados

- **Popover** — para conteúdo rico não estruturado como lista de ações.
- **Button** — o gatilho do menu é tipicamente um Button.
