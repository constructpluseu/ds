# Tree View <StatusBadge status="disponivel" />

Hierarquia navegável e expansível, para estruturas com níveis (ex.: obras agrupadas por tipo, pastas de documentos de uma obra).

## Quando usar

- Para representar dados com relação pai-filho clara e navegável, onde o utilizador pode querer ver só um ramo de cada vez.
- Quando os itens têm profundidade variável (alguns têm filhos, outros não).

## Quando não usar

- Para uma lista plana sem hierarquia — use `List` ou `Structured List`.
- Para navegação principal do produto — essa é a `Navegação (Shell)`, não este componente.

## Anatomia

Lista com `role="tree"`, cada item (`role="treeitem"`) com um indicador de expansão (▸/▾) quando tem filhos, e indentação proporcional à profundidade.

## Estados

| Estado | Comportamento |
|---|---|
| Fechado | Filhos não estão no DOM; indicador mostra ▸. |
| Aberto | Filhos visíveis; indicador mostra ▾; `aria-expanded="true"`. |
| Selecionado | Fundo destacado com a cor de acento. |
| Desativado | Não pode ser selecionado por clique nem por teclado; texto esbatido. |
| Em foco | Contorno visível à volta da linha; segue o padrão de *roving tabindex*. |

## Comportamento

- **Componente controlado**: `expandedIds` e `selectedId` são geridos pela aplicação; o `Tree View` só emite os pedidos de alteração (`onExpandedChange`/`expandedChange`, `onSelect`/`select`).
- Clicar no indicador ▸/▾ expande ou recolhe um nó sem o selecionar. Clicar no resto da linha seleciona o nó (se não estiver desativado).
- Navegação por teclado segue o padrão WAI-ARIA de árvore: `Seta para baixo`/`Seta para cima` movem o foco entre os nós atualmente visíveis; `Seta para a direita` expande um nó fechado ou move o foco para o primeiro filho de um nó já aberto; `Seta para a esquerda` recolhe um nó aberto ou move o foco para o nó-pai; `Enter`/`Espaço` seleciona o nó em foco.
- Só o nó em foco tem `tabindex="0"` (*roving tabindex*); os restantes têm `tabindex="-1"`, pelo que a árvore inteira ocupa uma só paragem no `Tab` da página.

## Conteúdo

- Rótulos curtos e reconhecíveis: **&ldquo;Moradia Cascais&rdquo;**, não um identificador técnico.
- Agrupe por um critério que faça sentido para quem gere obras (tipo, estado, ano), não pela estrutura interna da base de dados.

## Acessibilidade

- Usa o padrão WAI-ARIA de árvore com uma lista **plana** anotada com `aria-level`, `aria-posinset` e `aria-setsize` em vez de `<ul>` aninhados — uma alternativa válida ao aninhamento por DOM, prevista nas WAI-ARIA Authoring Practices, mais simples de gerar em todos os frameworks suportados.
- Nós com filhos declaram `aria-expanded`; nós sem filhos não declaram este atributo.
- O nó selecionado declara `aria-selected="true"`.
- O botão de expandir/recolher tem `aria-label` explícito ("Expandir"/"Recolher").

## Relacionados

- **Accordion** — disclosure de um só nível; use `Tree View` quando há mais de um nível de profundidade.
- **Structured List** — alternativa para listas sem hierarquia.
